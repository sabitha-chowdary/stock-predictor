# 📈 AI Stock Price Prediction Dashboard

An AI-powered stock market forecasting web application built using LSTM deep learning and deployed with Streamlit.

This project predicts future stock prices using historical market data and visualizes trends in an interactive dashboard.

## 🧠 Project Overview

This project uses a Long Short-Term Memory (LSTM) neural network to analyze historical stock prices and predict future values.

It is designed as a beginner-friendly but industry-style machine learning project for financial forecasting.

---

## 📊 Features

- 📈 Real-time stock data fetching  
- 🧠 LSTM-based price prediction model  
- 📉 Moving averages (50-day & 200-day)  
- 📊 Trading volume visualization  
- 🔮 Next-day stock price prediction  
- 🌐 Interactive web dashboard  

---

## 🛠️ Technologies Used

- Python 🐍  
- PyTorch (LSTM model)  
- Pandas & NumPy  
- Matplotlib  
- Scikit-learn  
- Yahoo Finance API  
- Streamlit (for UI)
